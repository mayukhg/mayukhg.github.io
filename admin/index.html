Connect to GitHub

The editor saves straight to your GitHub repository. You need a fine-grained personal access token once — it stays in this browser only and is sent only to api.github.com.

  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Under Repository access choose Only select repositories → mayukhg.github.io.
  3. Under Permissions → Repository permissions set Contents to Read and write. Nothing else is needed.
  4. Generate, copy the token and paste it below.

Help

How it works

  1. Connect once with a GitHub token (Connect tab).
  2. Edit any field. Your work is saved as a draft in this browser automatically.
  3. Preview draft opens the real site with your unpublished changes.
  4. Publish changes saves to GitHub. The live site updates in about a minute.

Formatting text

Fields marked rich support **bold text** and links written as [link text](https://example.com). Everything else is plain text.

Lists

Boxes marked “one per line” turn each line into a separate item — bullet points, tags or metric chips.

Linking experience to products

In a role's Related product IDs, list product IDs (from the Product portfolio tab), one per line. The site shows them as links under that role.

New résumé?

Upload the PDF on the Files tab, then update the matching text in Profile & résumé — the site text isn't read from the PDF.

Something went wrong?

Every publish is a normal GitHub commit, so any change can be undone from the repository history. Download backup saves your current draft as a file you can restore later.
